# Cash Effect

(שם הפרויקט והחבילה נשארים DailySpendOverlay, כדי שעדכונים יימשכו לעבוד.)

אפליקציית אנדרואיד שנועדה לדמות את **אפקט המזומן** ונלחמת ב"עיוורון הוצאות" (במזומן מרגישים את הכסף יוצא מהיד, בכרטיס או בטלפון לא): מיד אחרי כל תשלום קופצת חלונית גדולה עם **סכום העסקה** ועם **הסך היומי המצטבר**. כברירת מחדל אין תקציב והחלונית מציגה רק את הסכום. אם מגדירים תקציב יומי, היא כחולה כל עוד אתה מתחתיו, וכשאתה עובר אותו היא **אדומה**. היא נעלמת לבד אחרי 4 שניות, או מיד כשנוגעים בה.

- **קליטה פסיבית:** האפליקציה קוראת את ההתראות של אפליקציות התשלום (Google Wallet, max, ישראכרט, כאל, בנקים, bit…), כולל SMS מחברות האשראי.
- **זיהוי סכום ומטבע:** ₪, $, €, £ ועוד כ-25 מטבעות. קנייה במטבע זר מומרת למטבע הראשי.
- **כפילויות:** אותו סכום תוך 60 שניות נספר פעם אחת, למשל כש-Google Wallet וגם אפליקציית האשראי מדווחות על אותה קנייה.
- **עסקאות בתשלומים:** כברירת מחדל המתג "להציג רק הוצאות יומיות" דלוק, ועסקאות בתשלומים לא נספרות. כשמכבים אותו, הן נספרות במלואן ביום הקנייה.
- **מראה:** אפשר לבחור צבע לחלונית ולהגדיר בהירות באחוזים, וגם לבחור בין כרטיס קטן למסך מלא. חריגה מהתקציב תמיד באדום בולט.
- **פרטיות:** כל הנתונים נשמרים רק בטלפון, בלי שרת, בלי חשבון ובלי גיבוי לענן. חיבור לאינטרנט קיים רק לבדיקת עדכונים ולשערי מטבע, ורק אחרי שאישרת.
- **סוללה:** אין ריצה ברקע. המערכת מעירה את האפליקציה לשבריר שנייה רק כשמגיעה התראה.

## 4 הרכיבים המרכזיים בקוד

| רכיב | קובץ |
|---|---|
| 1. Manifest – הרשאות | `app/src/main/AndroidManifest.xml` |
| 2. קליטת התראות + Regex | `listener/SpendNotificationListener.kt`, `core/AmountParser.kt`, `listener/NotificationText.kt` |
| 3. זיכרון, חישוב יומי, תקציב | `core/DailyLedger.kt` (הלוגיקה), `data/SpendStore.kt` (SharedPreferences) |
| 4. החלונית הצפה | `overlay/OverlayManager.kt`, `res/layout/overlay_spend.xml` |

קבצים נוספים:
- `core/Currencies.kt` ו-`core/FxRates.kt` – מטבעות והמרות.
- `core/SourceRules.kt` – מאילו אפליקציות לספור.
- `MainActivity.kt` – מסך ההגדרות.
- `update/` – עדכון עצמי.
- `net/OnlineGateway.kt` – **הקובץ היחיד שפותח חיבור לאינטרנט**, ורק אחרי הסכמה.

בדיקות יחידה: `app/src/test/…/core/` (73 בדיקות ל-Regex, לחישוב היומי, לכפילויות ולהמרות).

## התקנה ראשונה – דרך GitHub (מומלץ, בלי לבנות כלום במחשב)

1. **פותחים חשבון GitHub** (חינם) ב-github.com, אם עוד אין לך.
2. **מעלים את הפרויקט:**
   - **הדרך הקלה:** פותחים את התיקייה ב-Android Studio, ואז בתפריט **VCS** (או **Git → GitHub**) בוחרים **Share Project on GitHub**. נותנים שם `DailySpendOverlay`, **מורידים את הסימון מ-Private** (הריפו חייב להיות ציבורי כדי שהאפליקציה תוכל להוריד עדכונים בלי סיסמה), ולוחצים Share.
   - קובץ הסיסמה `keystore/keystore.properties` **לא** יעלה, כי הוא ב-`.gitignore`, וזה בכוונה.
3. **מוסיפים את הסיסמה כ-Secret:** בריפו נכנסים ל-**Settings → Secrets and variables → Actions → New repository secret**.
   - שם: `KEYSTORE_PASSWORD`
   - ערך: הסיסמה שבשורה `storePassword=` בקובץ `keystore/keystore.properties`
4. **מריצים בנייה:** בלשונית **Actions** בוחרים **Build & Release APK** ולוחצים **Run workflow** (או Re-run, אם הריצה הראשונה נכשלה כי עוד לא היה Secret). אחרי כ-4 דקות נוצר **Release** עם הקובץ `DailySpendOverlay.apk`.
5. **בטלפון:** נכנסים לדף ה-Releases של הריפו, מורידים את `DailySpendOverlay.apk`, פותחים אותו ומאשרים "התקנה ממקור לא ידוע".

### דרך חלופית: Android Studio
פותחים את התיקייה ב-Android Studio (Ladybug 2024.2 ומעלה) ומחכים לסנכרון של Gradle. אחר כך מחברים טלפון במצב מפתחים ולוחצים ▶ Run, או בונים קובץ ב-**Build → Build App Bundle(s)/APK(s) → Build APK(s)**.
> אם Android Studio מציע לשדרג את Android Gradle Plugin, אפשר לסרב, כי הפרויקט עובד כמו שהוא.

## הגדרה בטלפון (פעם אחת)

כל ההגדרות מופיעות במסך האפליקציה עם כפתורי "אישור":

1. **גישה להתראות:** מפעילים את Cash Effect ברשימה.
   - **אנדרואיד 13 ומעלה:** אם המתג אפור, נכנסים לפרטי האפליקציה, פותחים את התפריט ⋮ למעלה, בוחרים **"התר הגדרות מוגבלות"** וחוזרים. זו הגבלה של אנדרואיד על אפליקציות שהותקנו מקובץ.
2. **הצגה מעל אפליקציות אחרות:** מפעילים.
3. **התקנת עדכונים** ("התקנת אפליקציות לא ידועות"): נדרש רק כדי שהאפליקציה תעדכן את עצמה.
4. **חיבור לאינטרנט:** בפתיחה הראשונה האפליקציה שואלת אם מותר לה להתחבר, רק לבדיקת גרסה חדשה ולשערי מטבע. אפשר לסרב, וכל השאר ימשיך לעבוד.

בדיקה מהירה: בכפתורים **"תצוגה מקדימה"** ו**"תצוגת חריגה"** רואים את החלונית בלי לשלם בפועל.

**סמסונג/שיאומי:** אם החלונית מפסיקה לקפוץ אחרי כמה ימים, צריך להוציא את האפליקציה מ"אפליקציות רדומות". בסמסונג: הגדרות → סוללה → הגבלות שימוש ברקע. ההחרגה הזו לא מגדילה את צריכת הסוללה, כי האפליקציה לא עושה כלום כשאין התראה.

## "התשלום שלי לא נספר" – יומן הזיהוי

במסך האפליקציה יש יומן של ההתראות האחרונות שבהן זוהה סכום, ולצד כל אחת כתוב מה קרה איתה:
- **✓ נספר**
- **כפילות** – אותו סכום תוך 60 שניות
- **סונן** – זיכוי, החזר, הנחה או כסף שנכנס
- **לא ברשימת המקורות** – לוחצים **"הוסף"**, ומעכשיו האפליקציה הזו תיספר.

רשימת המקורות ניתנת לעריכה, עם כלל אחד בכל שורה:
```
com.google.android.apps.walletnfcrel   # אפליקציה שלמה
com.some.bank|max                      # רק התראות שהכותרת שלהן מכילה "max"
sms:max                                # SMS שהשולח שלו הוא בדיוק "max"
```

## גרסה חדשה – "כותבים לקלוד והאפליקציה מתעדכנת"

1. כותבים לקלוד מה לשנות.
   - **הכי חלק:** לחבר את GitHub לקלוד (claude.ai → Settings → Connectors → GitHub). כך קלוד יכול לערוך את הריפו ישירות.
   - **אחרת:** מצרפים לשיחה את ה-ZIP של הפרויקט ומקבלים ZIP מעודכן, ואז ב-Android Studio עושים **Git → Commit and Push**.
2. כל שינוי מעלה את `versionCode` בקובץ `version.properties` וכותב מה חדש ב-`release-notes.txt`.
3. ‏GitHub בונה APK חתום ומפרסם Release, תוך כ-4 דקות.
4. פותחים את האפליקציה בטלפון, והיא שואלת **"גרסה חדשה – להתקין?"**. לוחצים "התקן", והיא מתעדכנת. הסכום היומי וההגדרות נשמרים.
   - Release חדש נוצר רק כש-`versionCode` עולה.
   - גיבוי בלי אינטרנט: הכפתור **"עדכון מקובץ"** מתקין APK שהורדת ידנית.

## ⚠ מפתח החתימה – לשמור!

- הקבצים `keystore/dailyspend.jks` ו-`keystore/keystore.properties` הם ה"זהות" של האפליקציה.
- כל עדכון חייב להיות חתום באותו מפתח, אחרת אנדרואיד יסרב להתקין אותו מעל הגרסה הקיימת.
- **את הסיסמה שב-`keystore.properties` כדאי לשמור גם במנהל סיסמאות.**
- קובץ ה-`.jks` עצמו מוצפן בסיסמה, ולכן בטוח להעלות אותו לריפו. הסיסמה לא.

## פרטים טכניים

- Kotlin, בלי AndroidX ובלי ספריות צד שלישי.
- ‏minSdk 26 (אנדרואיד 8), ‏targetSdk 35.
- גרסאות בנייה: AGP 8.7.3, ‏Gradle 8.10.2, ‏Kotlin 2.0.21.
- **הרשאות:**
  - `SYSTEM_ALERT_WINDOW` – החלונית.
  - `REQUEST_INSTALL_PACKAGES` ו-`UPDATE_PACKAGES_WITHOUT_USER_ACTION` – עדכון עצמי.
  - `INTERNET` – רק דרך `OnlineGateway`, ורק אחרי הסכמה.
  - גישה להתראות דרך `BIND_NOTIFICATION_LISTENER_SERVICE`.
- **שערי מטבע:** קובץ השערים היומי של הבנק המרכזי האירופי (ECB). בלי אישור לאינטרנט האפליקציה משתמשת בשערים משוערים מובנים מסוף אוקטובר 2026, ומסמנת אותם "משוער".
